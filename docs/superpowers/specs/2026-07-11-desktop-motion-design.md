# Desktop Motion Design

## Goal

为桌面端补充克制且有功能意义的动效，让页面切换、数据更新、菜单弹窗和按钮操作有清晰反馈，同时保持工具类产品的效率感。

## Motion language

- 页面内容使用 180–220ms 的淡入和 4px 内短距离位移。
- 列表行首次出现时轻微错峰，错峰只覆盖前几项，避免长列表等待。
- 菜单和弹窗使用 140–180ms 的淡入缩放；不使用弹簧、漂浮或卡片上移。
- 按钮按下时缩放至 0.97，刷新图标在请求期间旋转。
- 进度条宽度使用 300ms 平滑过渡，颜色变化同步完成。
- 侧栏继续使用现有宽度过渡，页面切换通过视图 key 重新触发内容进入。

## Accessibility and performance

- 遵循 `prefers-reduced-motion: reduce`，关闭动画和非必要平滑滚动。
- 只动画 `opacity`、`transform`、进度条宽度及已存在的侧栏尺寸。
- 不增加第三方动画依赖。

## Verification

- 使用静态测试确认页面切换 key、按压反馈、进度条过渡和 reduced-motion 规则存在。
- 运行桌面端生产构建及完整测试。
