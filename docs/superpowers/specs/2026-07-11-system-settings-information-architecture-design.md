# 系统设置分组与视觉优化设计

## 信息架构

- “CLI 启动”卡片包含默认终端和自动恢复，两项横向排列，窄屏时换行。
- “Codex 安装”卡片包含 CLI 与 App 两条紧凑路径设置，共享卡片标题和重新检测动作。
- 代理、日志维持独立卡片，避免混合运行配置与诊断功能。

## 交互与视觉

- 自动恢复使用 macOS 风格 38×22 开关，开启色为 `#34C759`，关闭为中性灰。
- 默认终端选择器显示本机应用图标和名称；列表项同步显示图标。
- 图标由 Electron `app.getFileIcon()` 从 `.app` 或 `.exe` 获取并转为 data URL；失败时使用终端图标兜底。
- 操作按钮降为次要视觉，路径行只保留保存与重置；重新检测作为组级操作。

## 安全与兼容

- renderer 只接收图标 data URL，不依赖本地文件路径渲染。
- 非终端 Select 不显示图标，不改变现有交互。
- 原有保存、重置、扫描、自动恢复数据流保持不变。
