## 用量总览

用量页面按环境、账号、Base URL 和模型汇总请求数、Input、Output、Cache Read、Token 和费用。远程供应商不返回完整计费数据时，费用会显示为 `-`。

## 请求详情

点击 Base URL 汇总中的 URL 进入请求详情。详情页展示时间、请求 ID、环境、账号、模型、端点、状态、各类 Token、延迟和费用，并提供“返回用量”按钮。

## 筛选与分页

详情页默认展示全部环境和全部账号；从某个 URL 进入时只把该 URL 作为初始筛选。环境、账号、模型、端点、状态和关键字都可以重新筛选，分页不会改变筛选范围。

## 趋势为空

趋势图需要请求记录包含有效时间和 Token 字段。若总量卡片有数据但趋势为空，先刷新数据并检查当前时间范围；只有无法聚合的旧记录时，趋势会保持空白而不影响明细表。
