## 同一环境切换

同一个环境下切换账号时，软件会关闭该环境全部受管 App 窗口，再使用新账号恢复相同数量的窗口，避免部分窗口继续使用旧凭证。

## 不同环境多窗口

不同环境拥有独立的 home 目录，可以同时打开多个窗口。窗口间不会共享会话、配置或账号状态。

## App 多开

账号页的 App 菜单会显示“多开”。只有当前活跃 App 账号可以使用；其他账号上的入口会置灰。每次多开成功后，软件会保存该环境的窗口数量，最多 8 个。以后切换该环境的账号时，所有窗口会一起切换并按保存数量重新打开。

## Windows MSIX

Windows 的 Codex App 可能通过 MSIX 激活。软件会优先使用可传入独立 profile 的执行别名；只有 `AppsFolder` 激活入口时，多开会提交多次窗口激活请求，最终是否创建独立窗口由安装的 App 版本决定。停止旧实例时遇到 `kill EPERM`，通常表示进程已由系统接管或已退出，可重新检查状态后启动。

## 对话恢复

设置中的“启动 CLI 时自动恢复最近第 N 次对话”只影响 CLI 启动命令。它不会把不同环境的历史混在一起，也不会替换当前账号凭证。
